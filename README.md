# 🍕 Pizza Sales Analysis — SQL Server & Excel Dashboard

An end-to-end data analytics project using **SQL Server and Microsoft Excel** to analyze pizza sales, 
calculate key performance indicators (KPIs), identify sales and ordering trends, and create a business-focused dashboard.

## 📌 Project Overview

This project analyzes pizza sales data to understand overall sales performance, 
ordering patterns, pizza category and size contribution, and best- and worst-performing products.

The analysis was performed using **SQL Server (SSMS)** for data querying and **Microsoft Excel** 
for calculations, validation, visualization, and dashboard development.

## 🛠️ Tools & Technologies

- **SQL Server**
- **SQL Server Management Studio (SSMS)**
- **SQL**
- **Microsoft Excel**
- Excel Charts & Graphs
- Excel Formulas
- Data Validation

## 🔄 Project Workflow

1. Imported pizza sales data into SQL Server.
2. Created and worked with the `pizza_sales` dataset.
3. Wrote SQL queries to solve defined business problem statements.
4. Calculated sales KPIs using SQL.
5. Analyzed daily and hourly order trends.
6. Analyzed sales contribution by pizza category and size.
7. Identified top and bottom-selling pizzas.
8. Exported SQL results to Excel.
9. Performed additional calculations and analysis in Excel.
10. Cross-checked Excel results with SQL outputs to validate accuracy.
11. Developed an Excel dashboard to present the final insights.

## 📊 Key Performance Indicators

The analysis calculates:

- **Total Revenue**
- **Average Order Value**
- **Total Pizzas Sold**
- **Total Orders**
- **Average Pizzas Per Order**

## 🔎 Analysis Performed

### 📅 Order Trends

- Daily trend of total orders
- Hourly trend of total orders
- Identification of high-order periods

### 🍕 Sales Analysis

- Percentage of sales by pizza category
- Percentage of sales by pizza size
- Total pizzas sold by pizza category
- Top 5 best-selling pizzas
- Bottom 5 pizzas by quantity sold

### 📈 Dashboard

The Excel dashboard brings the analysis together through KPI cards, charts, 
trend analysis, category and size analysis, and best/worst seller visualizations.

## 💡 Key Insights

The dashboard was used to identify:

- Busiest days based on total orders
- High-order hours throughout the day
- Sales contribution across pizza categories
- Sales contribution across pizza sizes
- Top-performing pizza products
- Low-performing pizza products

## ✅ Data Validation

To ensure consistency and accuracy, key calculations in Excel were cross-checked against the corresponding SQL Server query outputs.

This helped validate that the values presented in the final Excel dashboard matched the SQL analysis.
